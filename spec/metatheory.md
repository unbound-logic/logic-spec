# Formal Metatheory & Open Proof-Theoretic Boundaries (`UL-Core`)

This document formalizes the metatheoretic invariants of [core.md](core.md) (`v0.2.0`) and [worked-examples.md](worked-examples.md), and labels each result on the claim status ladder of [AGENTS.md](../AGENTS.md) §2 item 5: a `Tested` result is exercised by bound tests but not proved, a `Decided` result is ratified but not yet met by the reference kernel, and an `Exploratory` result is open.

No result below is `Proved` yet. MT-9 carries a written proof that awaits maintainer review; the proof sketches elsewhere are sketches, not proofs.

## 1. Well-Foundedness & Fixed-Point Semantics

1. `Exploratory` **MT-1: Acyclic Grounding, Least-Fixpoint `Live` Authority & Stratified Quarantine** ([core.md](core.md) §3 items 8, 10; [`layer3-structural-rules-and-cut`](../docs/design-review.md#layer3-structural-rules-and-cut)):
   - **Audit status**: the operator `F_Σ` below treats `Entries(Σ)` and `obstructed_Σ` as fixed inputs, which is not the semantics of [core.md](core.md) §3 item 10; MT-1 will be restated for the evaluation program ratified in [`audit-spec-kernel-coupling`](../docs/design-review.md#audit-spec-kernel-coupling).
   - **Statement**: Let `Entries(Σ)` be the finite set of derived and base ground entries generated in an inquiry state `Σ` over a finite signature and boundary system. Define `Live(Σ) ⊆ Entries(Σ)` as the least fixpoint `μL. F_Σ(L)` of the operator:
     ```text
     F_Σ(L) := { e ∈ Entries(Σ) | ¬obstructed_Σ(e) ∧ (base(e) ∨ structural(e) ∨ ∀d ∈ deps(e). d ∈ L) }
     ```
     where `obstructed_Σ(e)` holds iff there exists a non-empty `B' ⊑ boundary(e)` such that `(B', item(e))` is in local `Collision`. Then:
     1. `F_Σ` is monotone on `(𝒫(Entries(Σ)), ⊆)`, so by Knaster–Tarski `Live(Σ)` exists, is unique, and is reached in at most `|Entries(Σ)|` iterations (implemented in `src/engine.ts`).
     2. **Anti-Circularity**: Any mutual-support cycle `e₁ → e₂ → ... → e₁` with no unobstructed acyclic path back to `G⁺ ∪ G⁻ ∪ C_B` never enters `Live(Σ)`.
   - **Proof Sketch**: Monotonicity of `F_Σ` follows immediately because `¬obstructed_Σ(e)` does not depend on `L` and `∀d ∈ deps(e). d ∈ L` is positive in `L`. For anti-circularity, proceed by induction on Knaster–Tarski approximants `L_0 = ∅`, `L_{m+1} = F_Σ(L_m)`: if `C ⊆ Entries(Σ)` is a non-empty subset where every `e ∈ C` has some dependency `d ∈ deps(e) ∩ C`, no element of `C` can be the minimal-step entrant into any `L_m`, hence `C ∩ Live(Σ) = ∅`.
   - **Stratified Quarantine Resolution**: Under unstratified eager closure, a broad rule `B_all ⊩⁺ (A → C)` plus `B_all ⊩⁺ A` can emit a raw entry `e_C = (B_all, +C)` before `B_sub ⊩⁻ A` collides on `B_sub ⊑ B_all`, creating a **ghost collision** against an independent `B_sub ⊩⁻ C` (or emitting a ghost `+A` from a refuted conditional `X → A` when `+X ∧ -A` already holds). Moreover, mutual symmetric conflicts (`A ⊥_B C` with `+A` and `+C`) can leave symmetric conflict cycles unresolved under naive alternating passes alone and leak downstream ghosts along multi-hop `MP` chains—even when reverse conditionals (`Y → C`, `Y → ~A`, or `Y → ~C`) point from a downstream ghost back into the source conflict. Ratified in [core.md](core.md) §3 item 10 and implemented in `src/engine.ts` via a **Van Gelder alternating fixpoint + self-cyclic and subset-minimal ancestor filtering + source-SCC-internal symmetric conflict locking** (`defObstructed` / `mayPass` / `computeSourceSCCs` ignoring structural `bottom-excl` dependencies and filtering strict-superset ancestor sets), defeated premises, falsified conditionals, collided `counter-implies` antecedents, and single-source symmetric conflict cycles never fire downstream transmissive rules (`MP`, `∨E`, `∧I`, `⊥_B`, `≈_B`, `cover-glue`, `imposs-excl`), while local symmetric collision records and `O_rev` remain preserved. *(Cross-conflict mutual bridges where two distinct symmetric sources `A ⊥ C` and `D ⊥ E` attack each other via incomparable 2-hop ghost paths mark the explicit graph-theoretic boundary beyond single-source SCC isolation.)*

## 2. Self-Reference & Triviality Resistance

2. `Tested` **MT-2: Curry Firewall Soundness (Level Stratification & Mutual Strict Positivity)** ([core.md](core.md) §1 item 3; [worked-examples.md](worked-examples.md) §3; [`layer4-implication-and-curry-barrier`](../docs/design-review.md#layer4-implication-and-curry-barrier)):
   - **Statement**: Suppose every recursive item/boundary definition system `{X_i := F_i(X⃗)}` obeys:
     1. **Level Stratification**: Every reflection item `Refl_k(J)` occurring inside a level-`n` definition satisfies `level(J) ≤ k < n`; and
     2. **Mutual Strict Positivity**: In the directed dependency graph over `{X_i}`, no directed cycle traverses a **contravariant edge**—namely, passing to the left of `→`, inside an unguarded strong polarity flip `~` (that feeds a conditional or negative position), or inside a boundary promotion `[δ]` / quantifier domain constraint `D`.
     Then every admissible definition admits a well-founded denotational interpretation across the stratified hierarchy `M₀ ⊆ M₁ ⊆ ... ⊆ M_ω`, blocking Curry's Paradox (`⊢ Z` for arbitrary `Z`) across all four known attack vectors (`K := K → Z`, same-level `Refl` diagonal, `K := (~K) → Z`, and boundary-promotion `K := ∀(y : B ⊓ [K]) Z`).
   - **Proof Sketch**: Proceed by lexicographic induction on `(n, structural-depth)`:
     - Fix all evaluations `⊩⁺_k, ⊩⁻_k` at levels `k < n` (`M_{<n}`). Any `Refl_k(J)` with `k < n` acts as a fixed atomic predicate in `M_{<n}` whose positive/negative witness sets cannot shift while solving level `n`.
     - Within level `n`, contract non-contravariant DAG edges into finite strictly positive monotone operators over `(𝒫(Pos_n), 𝒫(Neg_n))` (note that `∧`, `∨`, right-hand side of `→`, and quantifier bodies preserve positivity). By Knaster–Tarski, each level-`n` recursive component admits a unique least fixpoint.
     - Vector 1 (`left-of-implies`), Vector 3 (`~` feeding `→`), and Vector 4 (`boundary-promotion`) each induce a self-loop with at least one contravariant edge and are syntactically rejected at formation time. Vector 2 fails same-level stratification (`n < n` impossible); well-typed cross-stage reflection `K_{t+1} := Refl_t(Σ_t ; B ⊩⁺ K_t) → Z` separates `K_t` from `K_{t+1}`, breaking Step 2 (`K ⊢ K → Z`) of the Curry derivation.
   - **Specification & Kernel Status**: Ratified in [core.md](core.md) §1 item 3 and enforced across `src/syntax.ts` (`checkRecursiveDefinitionSystem` and `collectBoundaryRefs`), `src/engine.ts` (`evaluateAtStage` + immutable `#stageArchive` snapshotting both inquiry state and `BoundarySystem` metadata via `BoundarySystem.clone()`, evaluating cross-stage reflection strictly against frozen `0 ≤ t < currentStage`, `level(J) ≤ k`, and stage-`t` boundary admissibility via `isReflectionWellScopedAtStage`), and `src/deduction.ts` (`refl-intro`).

3. `Tested` **MT-3: Non-Explosion & Non-Witnessing of `⊥` on Non-Empty Boundaries** ([core.md](core.md) §1 item 1, §2 item 4, §3 items 10–12; [`layer1-collision-quarantine`](../docs/design-review.md#layer1-collision-quarantine)):
   - **Statement**:
     1. **Global Non-Explosion**: If `(B, A)` enters `Collision` in state `Σ`, arbitrary unrelated items `Z` are **not** derivable (`B ⊩⁺ Z` does not follow from `Collision` on `(B, A)` alone).
     2. **Non-Witnessing of `⊥` (`Live` Safety)**: Under base admissibility (`⊥ ∉ G⁺`), no non-empty boundary `B ≠ ⊥_B` ever holds a `Live` positive witness `Σ ; B ⊩⁺ ⊥ [π]`.
   - **Proof Sketch**:
     - Part 1 follows by direct structural induction on the derivation calculus in [core.md](core.md) §3 items 9–12: no introduction rule accepts a pair `(⊩⁺ A, ⊩⁻ A)` as premises for an arbitrary conclusion `Z`. Rather, `Collision` sets `obstructed(B, A)` and removes `(B, A)` and its descendants from `Live(Σ)`.
     - Part 2 follows because `Σ ; B ⊩⁻ ⊥` holds structurally on every non-empty `B ≠ ⊥_B` ([core.md](core.md) §3 item 12). Thus, even if some chain yields a raw entry `(B, +⊥)`, `(B, ⊥)` immediately enters `Collision` and is non-`Live`. Furthermore, when `+(A → ⊥)` originates from structural boundary collapse (`B ⊓ [A] = ⊥_B`) or `Live`-gated `imposs-excl`, `B ⊩⁻ A` is induced directly, putting any competing `+A` in `Collision` before `Scoped Cut` (`MP`) can derive `+⊥`.
   - **Specification & Kernel Status**: Ratified in [core.md](core.md) §3 item 12 and enforced in `src/engine.ts`, which explicitly rejects direct `Observe⁺(B, ⊥)` on non-empty boundaries, downgrades `B ⊩⁻ (A → C)` to one-way counterexample introduction (`+A ∧ -C ⇒ -(A → C)`), and implements `Live`-gated `imposs-excl` (`+(A → ⊥) ⟹ -A`) without enabling Double Negation Elimination (`(A → ⊥) → ⊥ ⊬ A`) or Glivenko LEM inversion. Combined with Van Gelder stratification (`MT-1`), conflicting `Observe⁺(B, A → ⊥)` and `Observe⁺(B, A)` collides `(B, A → ⊥)` via `counter-implies` before `MP` can fire, emitting zero `+⊥` entries.

## 3. Boundary Algebra, Disjoint Isolation & Cover Stability

4. `Decided` **MT-4: Disjoint Regime Zero-Leakage & Selective Quarantine Survival** ([core.md](core.md) §2 item 4, §3 items 9–10; [worked-examples.md](worked-examples.md) §1):
   - **Audit status**: the disjointness premise can currently hold by omission; under [`audit-unregistered-meet-closed-world`](../docs/design-review.md#audit-unregistered-meet-closed-world) it requires declared disjointness.
   - **Statement**: Suppose `B₁, B₂ ≠ ⊥_B` are disjoint (`B₁ ⊓ B₂ = ⊥_B`). Suppose further that `Σ₁` extends `Σ₀` solely by adding a counterexample `Observe⁻(B₂, A, w)` (or derived exclusions native to `B₂`). Then:
     1. **Zero Negative Leakage**: For every non-empty sub-boundary `B' ⊑ B₁`, the exclusion `B₂ ⊩⁻ A` cannot inherit onto `B'`.
     2. **Local Non-Obstruction**: `(B₁, A)` itself is not obstructed by `Collision` on `(B₂, A)`.
     3. **Selective Survival**: Every ground `(B₁, ±Y [π])` that was `Live` in `Σ₀` and whose provenance DAG `π` contains no node `(B_sup, X)` with `B₂ ⊑ B_sup` remains `Live` in `Σ₁`.
   - **Proof Sketch**:
     - For (1), downward heredity transfers entries only to non-empty `B' ⊑ B₂`. Any `B'` with both `B' ⊑ B₁` and `B' ⊑ B₂` satisfies `B' ⊑ B₁ ⊓ B₂ = ⊥_B`, contradicting `B' ≠ ⊥_B`.
     - For (2), obstruction propagates strictly upward along `⊑` (a collision on `B_col` obstructs `(B_ext, A)` iff `B_col ⊑ B_ext`). Since `B₂ ⊑ B₁` would yield `⊥_B = B₁ ⊓ B₂ = B₂ ≠ ⊥_B` (contradiction), `B₂ ⋢ B₁`.
     - For (3), any node `(B_node, X)` in `π` with `B₂ ⋢ B_node` cannot become `obstructed` by any collision at or below `B₂`; by structural induction over the acyclic DAG `π`, every dependency in `π` remains in `Live(Σ₁)`, so `(B₁, ±Y [π]) ∈ Live(Σ₁)`.

5. `Decided` **MT-5: Meet-Stability of Cover-Witnessed Disjunction (`D2`) & Soundness of `∨E` Gluing** ([core.md](core.md) §2 item 5, §3 item 12; [`layer4-conjunction-disjunction-and-covers`](../docs/design-review.md#layer4-conjunction-disjunction-and-covers)):
   - **Audit status**: the proof sketch relies on Non-Vacuity, which the reference kernel does not maintain as boundaries are added; see [`audit-cover-non-vacuity-drift`](../docs/design-review.md#audit-cover-non-vacuity-drift).
   - **Statement**:
     1. **Downward Heredity of `D2` Disjunction**: If `Σ ; B ⊩⁺ (A ∨ C) [π]` is grounded by a witnessed exhaustive cover `{B₁, ..., B_k} ▷ B`, then for every non-empty sub-boundary `B' ⊑ B`, `{B_i ⊓ B' | B_i ⊓ B' ≠ ⊥_B} ▷ B'` witnesses `Σ ; B' ⊩⁺ (A ∨ C)`.
     2. **Soundness of Cover Gluing (`∨E`)**: From `Live` `B ⊩⁺ (A ∨ C)` (via `{B_i} ▷ B`), `Live` `B ⊩⁺ (A → E)`, and `Live` `B ⊩⁺ (C → E)`, every cell `B_i` acquires a `Live` witness `B_i ⊩⁺ E`, justifying `B ⊩⁺ E`.
   - **Proof Sketch**:
     - By Axiom 3 (Meet-Stability, [core.md](core.md) §2 item 5), `{B_i ⊓ B' | B_i ⊓ B' ≠ ⊥_B}` is a witnessed exhaustive cover of `B'`; by Axiom 5 (Non-Vacuity) and `B' ≠ ⊥_B`, this cover contains at least one non-empty cell `B_j ⊓ B'`. On each such cell `B_j ⊓ B' ⊑ B_j`, downward heredity (`§3 item 9`) inherits whichever of `B_j ⊩⁺ A` or `B_j ⊩⁺ C` held on `B_j`.
     - For `∨E`, downward heredity restricts both `B ⊩⁺ (A → E)` and `B ⊩⁺ (C → E)` to every cell `B_i ⊑ B`. Since each non-empty `B_i` has a `Live` witness for either `A` or `C`, `Scoped Cut` (`B_i ⊓ B_i = B_i ≠ ⊥_B`) produces `B_i ⊩⁺ E` on every cell of `{B_i} ▷ B`. Gluing across the exhaustive cover `{B_i} ▷ B` grounds `B ⊩⁺ E`.
   - **Standalone Gluing Status**: Ratified in [core.md](core.md) §3 item 12 and implemented both in `src/engine.ts` (`Rule I`, across both polarities) and as the `cover-glue` rule in `src/deduction.ts`, preserving Quarantine obstruction and selective base-leaf provenance.

## 4. Inquiry Dynamics & Anti-Immunization

6. `Tested` **MT-6: Polarity Purity of `Retract`, Reinstatement & Vertical Non-Commutativity** ([core.md](core.md) §2 item 7; [`layer4-negation-vs-exclusion`](../docs/design-review.md#layer4-negation-vs-exclusion)):
   - **Statement**:
     1. **Pure Cancellation (Sanskrit *prasajya-pratiṣedha*)**: Applying `Retract(g)` strictly deletes `g` from `G⁺ ∪ G⁻` without adding any element to either `G⁺` or `G⁻`. In particular, if `(B, A)` was `Grounded` (resp. `Excluded`) in `Σ` solely via a unique base leaf `g`, then in `Retract(g)(Σ)` the status of `(B, A)` becomes `Open`, never `Excluded` (resp. `Grounded`).
     2. **Quarantine Reinstatement**: If `(B, A)` was in `Collision` between `+A [g⁺]` and `-A [g⁻]`, then `Retract(g⁻)` removes the collision and restores `Live` authority to `+A [g⁺]` and any downstream derivations depending solely on `g⁺` and other `Live` leaves (without adding new positive leaves).
     3. **Vertical Non-Commutativity**: Vertical transition sequences `Σ₀ → Σ₁ → Σ₂` violate `Exchange` (`Observe⁺(B, A, w); Retract(w)` differs from `Retract(w); Observe⁺(B, A, w)`).
   - **Proof Sketch**: Immediate from the state transition definition (`§2 item 7`): `Retract(g)` modifies `Σ = (G⁺, G⁻, C_B, O_rev)` solely by set difference on `G⁺ ∪ G⁻` and re-evaluation of derived provenance. Since every derived entry for `±A` requires at least one base leaf in `G⁺ ∪ G⁻` (or structural `C_B`) by MT-1, deleting the sole base leaf eliminates all derived entries on that polarity without constructing an opposite-polarity leaf. Counterexample for (3): starting from `Open` `(B, A)` with `w ∉ G⁺`, `Observe⁺(B, A, w); Retract(w)` ends in `Open`, whereas `Retract(w); Observe⁺(B, A, w)` leaves `(B, A)` `Grounded`.

## 5. Four-Tier Specialization & Finite-Domain Classical Valuation

8. `Tested` **MT-8a: Constructive Specializations — No Quarantine Under `No-Gluts` and the Rule Sets of `NJ_min` and `NJ`** ([core.md](core.md) §3 item 12, §4 item 13; [`layer2-classical-boundary-recovery`](../docs/design-review.md#layer2-classical-boundary-recovery); [`audit-metatheorem-overclaim`](../docs/design-review.md#audit-metatheorem-overclaim)):
   - **Statement**:
     1. **`UL-Minimal`**: Under monotone `Σ` (forbidding `Retract`) and `No-Gluts` (no `(B, X)` in `Collision`), no ground is obstructed, so Quarantine never triggers, every well-founded ground is `Live`, and `Scoped Cut` acts as unrestricted `Cut`. The natural-deduction checker implements the rule schemas of [core.md](core.md) §3 item 12, which over `{∧, ∨, →, ∀, ∃, ⊥}` are those of minimal natural deduction `NJ_min`, with Nelson-style strong negation `~A` alongside `A → ⊥`, and it rejects derivations of `A ∨ ~A` and of `A` from `(A → ⊥) → ⊥`.

10. `Tested` **MT-9: `UL-Classical` Finite-Domain Bivalent Valuation (`2` on an Atomic Cell, `2^k` on a Finite Atomic Cover)** ([core.md](core.md) §4 item 13; [worked-examples.md](worked-examples.md) §4; [`scope-anchor-unified-core`](../docs/design-review.md#scope-anchor-unified-core); [`audit-metatheorem-overclaim`](../docs/design-review.md#audit-metatheorem-overclaim)).     - **Statement**: Assume the `UL-Classical` closure conditions (C1)–(C8) of [core.md](core.md) §4 item 13, and consider closed level-`0` items that mention only handles of `Dom(B*)`.
      1. **Atomic cell (`2`)**: On a non-empty atomic cell `B*`, setting `v(A) := 1` when `B* ⊩⁺ A` and `v(A) := 0` when `B* ⊩⁻ A` defines a total function on these items. It satisfies `v(⊥) = 0`, `v(~A) = 1 − v(A)`, `v(A ∧ C) = min(v(A), v(C))`, `v(A ∨ C) = max(v(A), v(C))`, `v(A → C) = max(1 − v(A), v(C))`, `v(∀(x : D) A(x)) = min_{w ∈ D_δ} v(A(w))` and `v(∃(x : D) A(x)) = max_{w ∈ D_δ} v(A(w))` with `D_δ` as in (C7), and whenever `v(t ≈_{B*} u) = 1`, `v(R(…, r: t, …)) = v(R(…, r: u, …))` for every relation `R` native to `B*`. Validity over finite structures differs from first-order validity (Trakhtenbrot's theorem), so MT-9 does not derive classical first-order consequence from `UL-Core`.
    - **Proof:** (written for v0.3.0 and revised after the maintainer's first review; MT-9 becomes `Proved` once the review is recorded.)
      - *Authority*: By (C4) no `(B, X)` is in `Collision` on any boundary of `Σ`, so no ground is obstructed and every derivable ground is `Live`. This holds under the v0.2.0 reading of [core.md](core.md) §3 item 10 and under the well-founded evaluation ratified in [`audit-spec-kernel-coupling`](../docs/design-review.md#audit-spec-kernel-coupling): there `Collision` is reported when the collision atom is true or undefined, so (C4) makes every collision atom false, obstruction never holds, the evaluation program has no effective negation, and its well-founded model is its least model, with no ground left `Undetermined`.
      - *Bivalence and clauses*, by structural induction on a closed level-`0` item `A` on `B*`; a constraint `δ` counts as a component of its quantifier, so each `δ(w)` falls under the induction hypothesis. In each case the induction hypothesis fixes the polarities of the components, an introduction rule of [core.md](core.md) §3 (or a closure rule of §4 item 13) derives the polarity the clause predicts, and (C4) excludes the opposite polarity. Only the introduction direction (`⟸`) of each clause of §3 item 12 is used.
        - Atoms and congruence items: (C5), since their handles lie in `Dom(B*)`.

        - `A ∧ C`: if `v(A) = v(C) = 1`, then `+A` and `+C` give `+(A ∧ C)`; otherwise `-A` or `-C` gives `-(A ∧ C)`. Hence `min`.
        - `A ∨ C`: if `v(A) = 1` or `v(C) = 1`, the identity cover `{B*} ▷ B*` (Axiom 2) witnesses `+(A ∨ C)`; otherwise `-A` and `-C` give `-(A ∨ C)`. Hence `max`.

        - `∀(x : D) A(x)` and `∃(x : D) A(x)`: by (C3), `Dom(D) ⊆ Dom(B*)` is finite and closed, so each instance `A(w)` and each `δ(w)` mentions only handles of `Dom(B*)` and is bivalent by the induction hypothesis. This fixes `D_δ`, which is non-empty for universals by (C8). Exactly one side of each clause of (C7) then holds, giving `min` and `max` over `D_δ`.
        - Congruence: if `v(t ≈_{B*} u) = 1`, substitutivity (§2 item 6), which applies to both polarities, carries `+R(…, r: t, …)` to `+R(…, r: u, …)` and `-R(…, r: t, …)` to `-R(…, r: u, …)`. Both instances are bivalent, so `v(R(…, r: u, …)) = v(R(…, r: t, …))`.

A classical tautology `T` has `vᵢ(T) = 1` on every cell, since each `vᵢ` is a classical valuation by part 1, so `B ⊩⁺ T`. ∎
