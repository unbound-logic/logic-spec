# Unbound Logic Core Specification (`UL-Core`)

This document is the normative formal specification for the core system (`UL-Core`) and its explicit boundary specializations (`UL-Minimal`, `UL-Intuitionistic`, `UL-Classical`). It formalizes the Phase 1 consensus recorded in [docs/design-review.md](../docs/design-review.md) and obeys the semantic boundaries in [docs/glossary.md](../docs/glossary.md) and [AGENTS.md](../AGENTS.md).

All normative items below carry an explicit claim status label (`Consensus` or `Exploratory`) for machine verification by `spec-graph`.

---

## 1. Syntax, Stratification & Content Grammar

1. `Consensus` **Role-Indexed Atomic Items (`G3`)** ([`layer5-content-and-coreference`](../docs/design-review.md#layer5-content-and-coreference)):
   - A signature specifies relation symbols `R` with finite role sets `{r₁, ..., r_n}` (`n ≥ 0`), handle variables `x, y, ...`, handle constants/terms `t, u, w, ...`, and boundary expressions `B, D, ...`.
   - An atomic evaluable item has the role-indexed relational form `R(r₁: t₁, ..., r_n: t_n)`. Unary predicates `P(t)` are the `n = 1` special case; processes, measurements, and multi-party relations are first-class without substance-attribute priority.
   - Reserved atomic forms:
     - **Unsatisfiable item `⊥`**: an item that admits no witness on any non-empty boundary (`B ≠ ⊥_B`) and is structurally excluded on every non-empty boundary.
     - **Boundary-scoped equivalence `t₁ ≈_B t₂`**: asserts congruence of handles `t₁` and `t₂` with respect to all relations native to boundary `B`.

2. `Consensus` **Compound Evaluable Items**:
   - Evaluable items `A, C` at stratification level `n ∈ ℕ` are inductively generated by:
     ```text
     A, C ::= R(r₁: t₁, ..., r_n: t_n)
            | ⊥
            | t₁ ≈_B t₂
            | ~A                     (strong polarity flip)
            | A ∧ C                  (conjunction)
            | A ∨ C                  (cover-witnessed disjunction)
            | A → C                  (scoped conditional)
            | ∀(x : D) A(x)          (boundary-scoped universal)
            | ∃(x : D) A(x)          (boundary-scoped existential)
            | Refl_k(J)              (reflection on a judgment J of strictly lower level k < n)
     ```
   - **Structural Impossibility Shorthand**: `¬_⊥ A` is defined as `A → ⊥`.

3. `Consensus` **Stratified Reflection & Strict Positivity (Curry Firewall)** ([`layer4-implication-and-curry-barrier`](../docs/design-review.md#layer4-implication-and-curry-barrier)):
   - Every item `A` and judgment carries a stratification level `n ∈ ℕ` (and, during vertical evolution, an inquiry stage index `t ∈ ℕ`).
   - **Level Stratification**: Any reflection item `Refl_k(J)` asserting the status (`Open`, `Grounded`, `Excluded`, `Collision`) or provenance of a level-`k` judgment `J` (or stage-`t` inquiry state `Σ_t`) has level strictly `n ≥ k + 1` (and stage `≥ t + 1`). Same-level self-referential equivalence `K_n ≡ (K_n → Z)` is ill-formed.
   - **Strict Positivity**: Recursive item or boundary definitions `X := F(X)` are admissible only when every occurrence of `X` in `F(X)` is **strictly positive** (never occurring to the left of `→` or inside an unguarded polarity flip `~` that feeds a conditional antecedent) and well-founded.

## 2. Boundary Algebra & Inquiry State Dynamics

4. `Consensus` **Boundary Meet-Semilattice `(B, ⊑, ⊓, ⊤_B, ⊥_B)`** ([`layer1-scope-factorization`](../docs/design-review.md#layer1-scope-factorization), [`layer3-boundary-composition`](../docs/design-review.md#layer3-boundary-composition)):
   - A **Domain Boundary `B`** is a functional constraint-frame role (a condition held fixed as `B` in one inquiry may be evaluated as an item `A` in another).
   - Boundaries form a bounded meet-semilattice:
     - **Refinement (`⊑`)**: reflexive, antisymmetric (up to boundary equivalence), transitive partial order (`B' ⊑ B` reads "`B'` is a sub-regime at least as restrictive as `B`").
     - **Meet / Overlap (`⊓`)**: idempotent, commutative, associative greatest lower bound (`B₁ ⊓ B₂`). Two boundaries **overlap** iff `B₁ ⊓ B₂ ≠ ⊥_B`, and are **disjoint** iff `B₁ ⊓ B₂ = ⊥_B`.
     - **Top (`⊤_B`)**: unrestricted global frame (`B ⊑ ⊤_B` for all `B`).
     - **Empty / Impossible Boundary (`⊥_B`)**: bottom element (`⊥_B ⊑ B` for all `B`). **Non-Witnessing Law**: `⊥_B` has no realizable domain and **cannot supply any genuine positive Witness (`+`)**.
   - **Adjoining a Constraint (`B ⊓ [A]`)**: Where an evaluable item `A` is promoted to a boundary constraint `[A]`, structural collapse occurs iff `B ⊓ [A] = ⊥_B`.

5. `Consensus` **Witnessed Exhaustive Covers (`{B_i} ▷ B`)** ([`layer4-conjunction-disjunction-and-covers`](../docs/design-review.md#layer4-conjunction-disjunction-and-covers)):
   - A finite family `{B₁, ..., B_k}` is a **witnessed exhaustive cover** of `B` (written `{B_i} ▷ B` or `B = ⨆_{i=1}^k B_i`) only when structurally witnessed under the following finitary coverage axioms:
     1. **Refinement**: For every `i`, `B_i ⊑ B`.
     2. **Identity**: `{B} ▷ B` for every `B ≠ ⊥_B`; `∅ ▷ ⊥_B`.
     3. **Meet-Stability (Base Change)**: If `{B_i} ▷ B` and `B' ⊑ B`, then `{B_i ⊓ B' | B_i ⊓ B' ≠ ⊥_B} ▷ B'`.
     4. **Transitivity (Composition)**: If `{B_i} ▷ B` and `{B_{i,j}} ▷ B_i` for every `i`, then `{B_{i,j}} ▷ B`.
     5. **Non-Vacuity**: For every `B ≠ ⊥_B`, `∅ ▷ B` never holds.

6. `Consensus` **Co-Reference & Individuation Across Updates (`≈_B`, `I_B`)** ([`layer5-content-and-coreference`](../docs/design-review.md#layer5-content-and-coreference)):
   - Each handle `t` admissible in `B` (written `t ∈ Dom(B)`) carries an explicit boundary-relative **individuation criterion `I_B(t)`**.
   - `≈_B` is a witnessed congruence on `Dom(B)`: reflexive, symmetric, transitive on unquarantined grounds, and substitutive for every relation `R` native to `B`:
     - If `B ⊩⁺ (t₁ ≈_B t₂)` and `B ⊩⁺ R(..., r: t₁, ...)`, then `B ⊩⁺ R(..., r: t₂, ...)` (and identically for `⊩⁻`), recording provenance on both premises.
   - **Multi-Granularity Isolation**: Refining `B_macro` to a finer regime `B_micro ⊑ B_macro` may introduce finer relations not native to `B_macro`; `t₁ ≈_{B_macro} t₂` and `t₁ ≉_{B_micro} t₂` coexist without conflict because congruence is indexed by its boundary.
   - **Anti-Equivocation**: In a vertical update `Σ_t → Σ_{t+1}`, new evidence concerning handle `t'` interacts with prior grounds on `(B, A(t))` only if `B ⊩⁺ (t' ≈_B t)` is witnessed under `I_B`.

7. `Consensus` **Inquiry States `Σ`, Vertical Updates & Anti-Immunization (`M1`, `M2`)** ([`zetetic-friction-source`](../docs/design-review.md#zetetic-friction-source), [`layer3-boundary-composition`](../docs/design-review.md#layer3-boundary-composition), [`layer5-content-and-coreference`](../docs/design-review.md#layer5-content-and-coreference)):
   - An **Inquiry State `Σ`** is a finite state tuple `(G⁺, G⁻, C_B, O_rev)` containing base positive witnesses `G⁺`, base negative exclusions `G⁻`, declared boundary constraints/covers/incompatibilities `C_B`, and open **Revision Obligations `O_rev`**.
   - Vertical evolution `Σ₀ → Σ₁ → ...` is **ordered and non-commutative** (`Exchange` does not hold vertically) and proceeds via four explicit transitions:
     1. **`Observe⁺(B, A, w)` / `Observe⁻(B, A, w)`**: Add a base witness or exclusion anchored by primitive justification `w` on non-empty `B ≠ ⊥_B`.
     2. **`Retract(g)` (Pure Cancellation, Sanskrit *prasajya-pratiṣedha*)** ([`layer4-negation-vs-exclusion`](../docs/design-review.md#layer4-negation-vs-exclusion)): Withdraw a specific base ground `g` (e.g., discredited observation or defective refutation) from `G⁺` or `G⁻`, recomputing derived grounds via provenance DAGs so `(B, A)` returns toward `Open` without fabricating the opposite polarity.
     3. **`RefineBoundary(B → B' = B ⊓ [δ])`**: Discharge a collision on `B` caused by counterexample `-A(w)` by narrowing the regime to `B'`, strictly subject to BOTH anti-immunization laws:
        - **M2 (Non-Erasure Scope-Shrinkage)**: Narrowing `B` to `B'` never erases the refutation on `B`; `(B, ∀(x : B) A(x))` remains `Excluded (-)` while `(B', ∀(x : B') A(x))` carries explicit narrowing provenance.
        - **M1 (Structural Admissibility)**: The splitting condition `δ(x)` must satisfy (i) **Non-Circularity** (`δ` does not reference `A` directly or indirectly) and (ii) **Non-Contingent Structural Definability** (`δ` cannot exclude `w` merely by its contingent empirical handle tag `x ≉ specimen_402`, while permitting structurally defined singularities of `B`'s own operations such as the additive identity `0` in `ℝ \ {0}`).
     4. **`Constrain(A ⊥_B C)` / `WitnessCover({B_i} ▷ B)`**: Register a witnessed material incompatibility or verified exhaustive cover in `C_B`.

## 3. Dual-Polarity Semantics, Provenance & Derivation Calculus

8. `Consensus` **Dual-Polarity Judgments & Well-Founded DAG Provenance** ([`layer1-dual-polarity`](../docs/design-review.md#layer1-dual-polarity), [`layer3-structural-rules-and-cut`](../docs/design-review.md#layer3-structural-rules-and-cut)):
   - For non-empty `B ≠ ⊥_B` in state `Σ`, the two primitive judgment forms are:
     - `Σ ; B ⊩⁺ A [π]` — `A` has positive **Witness** on `B` justified by provenance DAG `π`.
     - `Σ ; B ⊩⁻ A [π]` — `A` has negative **Exclusion** on `B` justified by provenance DAG `π`.
   - **Well-Foundedness Law**: Every valid provenance `π` is a finite **acyclic DAG** whose leaves are base grounds in `G⁺ ∪ G⁻` or structural axioms in `C_B`. Mutual-support cycles confer zero grounding.
   - **Derived Local Statuses** of `(B, A)` in `Σ`:
     - `Open`: no valid `π⁺` for `B ⊩⁺ A` and no valid `π⁻` for `B ⊩⁻ A`.
     - `Grounded`: at least one valid `π⁺` and no valid `π⁻` (and unobstructed on sub-boundaries; see item 10).
     - `Excluded`: at least one valid `π⁻` and no valid `π⁺` (and unobstructed on sub-boundaries).
     - `Collision`: at least one valid `π⁺` and at least one valid `π⁻` on `B`.

9. `Consensus` **Symmetric Downward Heredity & Meet Collision** ([`layer3-boundary-composition`](../docs/design-review.md#layer3-boundary-composition)):
   - Both polarities inherit **downward** to every non-empty sub-boundary `B' ⊑ B` (`B' ≠ ⊥_B`):
     - `Σ ; B ⊩⁺ A [π]` and `B' ⊑ B` (`B' ≠ ⊥_B`) ⇒ `Σ ; B' ⊩⁺ A [Down(B→B', π)]`.
     - `Σ ; B ⊩⁻ A [π]` and `B' ⊑ B` (`B' ≠ ⊥_B`) ⇒ `Σ ; B' ⊩⁻ A [Down(B→B', π)]`.
   - **Meet Collision Corollary**: Whenever `Σ ; B₁ ⊩⁺ A [π₁]` and `Σ ; B₂ ⊩⁻ A [π₂]` with `B₁ ⊓ B₂ ≠ ⊥_B`, downward heredity forces `(B₁ ⊓ B₂, A)` into `Collision`. Disjoint regimes (`B₁ ⊓ B₂ = ⊥_B`) never collide and never leak `-A` across disjoint sub-boundaries.

10. `Consensus` **Inference Quarantine, Sub-Boundary Obstruction & Revision Obligation** ([`layer1-collision-quarantine`](../docs/design-review.md#layer1-collision-quarantine), [`layer3-structural-rules-and-cut`](../docs/design-review.md#layer3-structural-rules-and-cut)):
    - **No Explosion**: `Collision` on `(B, A)` never licenses deriving arbitrary items `Z` (`Ex Falso Quodlibet` is excluded from `UL-Core`).
    - **Transmission Authorization (`Live`)**: A ground `Σ ; B ⊩± A [π]` is **transmission-authorized (`Live`)** iff:
      1. Every node `(B_k, X_k)` along provenance DAG `π` is itself `Live` (not quarantined); and
      2. `(B, A)` is **unobstructed** on `B`: there exists **no** non-empty sub-boundary `B' ⊑ B` where `(B', A)` is in `Collision`.
    - **Quarantine Propagation**: If `(B', A)` enters `Collision` (for any non-empty `B' ⊑ B`), then:
      - `(B', A)` and the obstructed broad ground `(B, ±A)` lose `Live` authority immediately;
      - Any downstream derived ground `Y [π_Y]` whose DAG `π_Y` passes through an un-`Live` node loses `Live` authority, while `Y` remains `Live` if it possesses an independent well-founded DAG `π'_Y` whose nodes are all `Live`;
      - A **Revision Obligation** `Rev(B', A)` is recorded in `O_rev` until discharged via `Retract` or `RefineBoundary` (obeying M1 + M2).

11. `Consensus` **Structural Rules & Scoped Cut** ([`layer3-structural-rules-and-cut`](../docs/design-review.md#layer3-structural-rules-and-cut)):
    - **Reflexivity**: Local ground records (`⊩⁺`/`⊩⁻`) are preserved even under `Collision`, but reflexive transmission requires `Live` authorization.
    - **Horizontal Exchange & Contraction**: Within fixed `Σ`, co-present `Live` grounds are order-independent (Exchange) and freely reusable across multiple derivations (horizontal Contraction; Curry's Paradox is blocked by item 3).
    - **Scoped Cut**: If `Σ ; B₁ ⊩⁺ A [π₁]` is `Live` and `Σ ; B₂ ⊩⁺ (A → C) [π₂]` is `Live` with `B₁ ⊓ B₂ ≠ ⊥_B`, then `Σ ; (B₁ ⊓ B₂) ⊩⁺ C [MP(π₁, π₂)]` (and transitively along any `Live` uncontested chain `A → C` and `C → E` on overlapping meets).
    - **Non-Monotonicity**: Horizontal addition of new exclusions and vertical updates `Σ_t → Σ_{t+1}` are non-monotonic whenever they introduce a new `Collision` or `Retract` a base leaf.

12. `Consensus` **Connective & Quantifier Polarity Rules (on non-empty `B ≠ ⊥_B`)** ([`layer4-negation-vs-exclusion`](../docs/design-review.md#layer4-negation-vs-exclusion), [`layer4-implication-and-curry-barrier`](../docs/design-review.md#layer4-implication-and-curry-barrier), [`layer4-conjunction-disjunction-and-covers`](../docs/design-review.md#layer4-conjunction-disjunction-and-covers), [`layer5-content-and-coreference`](../docs/design-review.md#layer5-content-and-coreference)):
    - **Unsatisfiable Item `⊥`**:
      - `⊩⁺ ⊥`: never holds on any `B ≠ ⊥_B`.
      - `⊩⁻ ⊥`: holds structurally on every `B ≠ ⊥_B`.
    - **Strong Polarity Flip (`~A`, Sanskrit *paryudāsa*)**:
      - `B ⊩⁺ (~A)` ⟺ `B ⊩⁻ A`
      - `B ⊩⁻ (~A)` ⟺ `B ⊩⁺ A`
    - **Material Incompatibility (`A ⊥_B C ∈ C_B`)**:
      - If `B ⊩⁺ A [π]` is `Live`, derive `B ⊩⁻ C [Incompat(π, A ⊥_B C)]`; symmetrically, `Live` `B ⊩⁺ C [π]` derives `B ⊩⁻ A [Incompat(π, A ⊥_B C)]`.
    - **Structural Impossibility (`A → ⊥`)**:
      - If adjoining `A` as a boundary constraint collapses `B` (`B ⊓ [A] = ⊥_B`), derive `B ⊩⁺ (A → ⊥)` and `B ⊩⁻ A` (double structural impossibility `(A → ⊥) → ⊥` does **not** derive `B ⊩⁺ A`).
    - **Conjunction (`A ∧ C`)**:
      - `B ⊩⁺ (A ∧ C)` ⟺ `B ⊩⁺ A` and `B ⊩⁺ C` (both `Live`, joining DAGs).
      - `B ⊩⁻ (A ∧ C)` ⟺ `B ⊩⁻ A` or `B ⊩⁻ C`.
    - **Cover-Witnessed Disjunction (`A ∨ C`)**:
      - `B ⊩⁺ (A ∨ C)` ⟺ there exists a witnessed finite exhaustive cover `{B₁, ..., B_k} ▷ B` (item 5) such that for each non-empty cell `B_i`, `B_i ⊩⁺ A` (`Live`) or `B_i ⊩⁺ C` (`Live`).
      - `B ⊩⁻ (A ∨ C)` ⟺ `B ⊩⁻ A` and `B ⊩⁻ C`.
      - **Cover Gluing (`∨E`)**: If `B ⊩⁺ (A ∨ C)` via `{B_i} ▷ B`, `B ⊩⁺ (A → E)` (`Live`), and `B ⊩⁺ (C → E)` (`Live`), then `B ⊩⁺ E` (grounded by gluing the per-cell derivations across `{B_i}`).
    - **Scoped Conditional (`A → C`)**:
      - `B ⊩⁺ (A → C)`: witnessed by a verified construction/transmission rule mapping any `Live` `B' ⊩⁺ A [π]` on any non-empty `B' ⊑ B` to `B' ⊩⁺ C [f(π)]` (so mere absence of `+A`, or defeasible `-A`, does **not** fabricate `+(A → C)` in `UL-Core`).
      - `B ⊩⁻ (A → C)` ⟺ `B ⊩⁺ A` and `B ⊩⁻ C` (preserving symmetric downward heredity without leaking counterexamples across disjoint sibling boundaries; any counterexample on `B' ⊑ B` yields `B' ⊩⁻ (A → C)`, colliding with inherited `B' ⊩⁺ (A → C)` and triggering upstream obstruction of `(B, +(A → C))` per item 10).
    - **Boundary-Scoped Quantifiers (`∀(x : D) A(x)`, `∃(x : D) A(x)` evaluated at `B`)**:
      - `B ⊩⁺ ∀(x : D) A(x)` ⟺ generic structural grounding showing `B ⊩⁺ A(x)` for arbitrary admissible `x ∈ Dom(D)` (or per-cell grounding across a witnessed finite cover of `D`).
      - `B ⊩⁻ ∀(x : D) A(x)` ⟺ there exists concrete `w ∈ Dom(D)` with `B ⊩⁻ A(w)`.
      - `B ⊩⁺ ∃(x : D) A(x)` ⟺ there exists concrete `w ∈ Dom(D)` with `B ⊩⁺ A(w)`.
      - `B ⊩⁻ ∃(x : D) A(x)` ⟺ generic structural exclusion showing `B ⊩⁻ A(x)` for all admissible `x ∈ Dom(D)`.

## 4. Boundary Specialization Theorems

13. `Consensus` **Four-Tier Deductive Spectrum** ([`scope-anchor-unified-core`](../docs/design-review.md#scope-anchor-unified-core), [`layer2-classical-boundary-recovery`](../docs/design-review.md#layer2-classical-boundary-recovery)):
    - Every specialization below is obtained purely by imposing explicit closure constraints on `(B, Σ)` without altering or contradicting items 1–12 of `UL-Core`:
    1. **`UL-Core`** (General Regime): Items 1–12 with no additional closure constraints. Supports partial information (`Open`), localized `Collision` with Quarantine, non-monotonic vertical revision, multi-granularity `≈_B`, and stratified reflection.
    2. **`UL-Minimal`** (Minimal Constructive Specialization):
       - *Closure conditions*: Restrict vertical transitions to monotone growth (forbid `Retract`) and enforce **`No-Gluts`** (no `(B, A)` is in `Collision`).
       - *Consequences*: Quarantine never triggers; every valid ground is `Live`; `Scoped Cut` becomes unrestricted `Cut`; `∧`, `∨` (Beth covers), `→`, `∀`, `∃`, `A → ⊥`, and `~A` satisfy **Minimal Constructive Logic** (with Nelson-style strong negation `~A` alongside `A → ⊥`), rejecting both Excluded Middle and Double Negation Elimination for `A → ⊥`.
    3. **`UL-Intuitionistic`** (Heyting Constructive Specialization):
       - *Closure conditions*: `UL-Minimal` plus the boundary axiom **`⊥ → C`** for every item `C` (sound under `No-Gluts` because `⊥` has no witness on any non-empty `B ≠ ⊥_B`, so Modus Ponens never fires from `⊥`).
       - *Consequences*: Recovers **Heyting Intuitionistic First-Order Logic** under finitary Beth cover semantics (item 5 & item 12).
    4. **`UL-Classical`** (Classical First-Order Specialization):
       - *Closure conditions*: Freeze `Σ` (no vertical updates), fix a closed atomic boundary `B* ≠ ⊥_B` (or a witnessed finite cover of atomic cells) with finest congruence `≈_{B*}`, enforce **`No-Gluts`**, enforce **`No-Gaps`** (no item is `Open` on any atomic cell), and restrict to object level `n = 0`.
       - *Derived Theorems*:
         - **Bivalence & Provenance Projection**: Every item on `B*` is strictly `Grounded (+)` or `Excluded (-)`; provenance DAGs project safely onto `{1, 0}`.
         - **Negation Collapse**: On `B*`, `-(A → ⊥) ⟺ +A ∧ -⊥ ⟺ +A`, so by `No-Gaps` + `No-Gluts`, `+(A → ⊥) ⟺ -A ⟺ +(~A)`. Both `~A` and `A → ⊥` collapse extensionally to classical Boolean `¬A` with Double Negation Elimination.
         - **Material Implication Recovery**: On `B*`, `-(A → C) ⟺ +A ∧ -C`; by `No-Gaps`, every non-refuted conditional closes to `+(A → C) ⟺ (-A ∨ +C)`, while `No-Gluts` guarantees Modus Ponens never fires when `-A` holds.
         - **Excluded Middle & Connective Truth Tables**: `∧`, `∨` (via D2 cover over atomic cells), `∀`/`∃` (over `Dom(B*)`), and `≈_{B*}` recover classical truth tables, `+(A ∨ ~A)` (LEM), De Morgan quantifier duality, and Leibnizian equality `=`.
         - **Vacuous Explosion**: Under `No-Gluts`, the set of states satisfying both `+A` and `-A` is empty, so classical Explosion (`A, ~A ⊢ C`) holds vacuously as a specialization theorem without belonging to `UL-Core`.
